# Canned template: course details for contentless enquiries

**Use only when the message has no real question** — empty body, or a single word / bare phrase like "Inquiry", "Interested", "Course details", "Thank you", "Info".

**Never use it when the person asked something specific**, however brief. A real question gets a real, tailored reply. See the usage rules in SKILL.md.

Send verbatim. Do not pad it with extra warmth, a personal anecdote, or a pitch — its job is to be clean and complete.
